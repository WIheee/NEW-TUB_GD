## Code PR B3

第三个 beta：品牌正式更名为 **Code PR**，包名与仓库地址全面切换，把排除规则彻底交给用户，并移除副作用明显的零拷贝。

### 新增

- **排除规则完全可编辑**：内置默认规则首次启动时自动并入列表，之后可以像自定义规则一样自由添加、删除
- 设置页新增「恢复默认」：误删内置规则后可一键找回
- 默认软排除规则现在真正参与扫描（此前只展示、不生效）

### 改进

- 应用名、首页标题与「关于」统一为 **Code PR**
- 包名 / applicationId 改为 `com.wihee.code.pr`
- 仓库地址统一为 `https://github.com/WIheee/Code-pr`（「关于」跳转与公告拉取）
- 原生库名改为 `codepr`，JNI 符号同步更新
- 内置提示词「TUB 同款」更名为「Code PR 同款」
- **公告逻辑优化**：版本更新公告每次启动都会检查，目标版本高于本机才提示；已经是最新版本时直接忽略，有新版本则每次启动提醒直到更新
- **移除实验性零拷贝写入**：流式导出统一走字符路径，字符数/行数与内存模式一致；设置页不再显示该开关
- 版本号升级为 `B3`（versionCode 185）

### 修复

- 删除内置默认规则后无法重新添加的问题（重复校验不再参照已删除的默认集合）

### 构建信息

- JDK 21 / Gradle 9.0 / AGP 8.13
- compileSdk 37 / targetSdk 34 / minSdk 28
- NDK 30.0.15729638 / CMake 4.1.2

### 已知限制

- XML 导出仍走文本路径（CDATA 转义需要）
- 当前只打包 arm64-v8a

### 升级说明

> **B3 更换了包名，不能覆盖安装。**

- 旧版 `com.godot.tub.gd` 与新版本 `com.wihee.code.pr` 在系统中是两个独立应用
- 请先备份需要的导出文件，再卸载旧版并安装 B3
- 旧版的设置、历史记录与自定义提示词不会自动迁移
