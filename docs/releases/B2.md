## Code PR B2

第二个 beta，重点是**让 AI 更容易读到你的要求**：提示词前移、可自定义，并加入基于 GitHub 的应用内公告。

### 新增

- **公告系统**：应用启动时静默拉取仓库根目录的 `Announcement.md`，公告 ID 大于本机已读 ID 时弹窗；`action: update` 的公告提供「前往更新」，跳转 GitHub Releases
- **自定义提示词**：任意内置提示词可「复制并修改」，也可以从零新建；支持 `{{version}}` 占位符，导出时替换为识别到的 Godot 版本
- 首页右上角公告入口（喇叭图标），可随时手动查看
- `Announcement.md`：公告数据源，含格式说明与模板，提交到 `main` 即生效，不用发版

### 改进

- **提示词移到文档最前面**：先给任务约束，再给目录树与源码；内置文案里的 "above" 相应改为 "follow/below"
- 设置页「AI 提示词」改为管理器：内置列表 + 我的提示词，选中项高亮，支持编辑与删除
- 「关于」中的仓库地址统一为 `https://github.com/WIheee/Code-pr`

### 其他

- 新增 `INTERNET` 权限（仅用于拉取公告）

### 构建信息

- JDK 21 / Gradle 9.0.0 / AGP 8.13.0
- compileSdk 37 / targetSdk 34 / minSdk 28
- NDK 30.0.15729638 / CMake 4.1.2
- versionCode 184 / versionName B2

### 已知限制

- 复制内置提示词得到的是生成时的快照，版本专属规则不会随后续检测自动变化
- 零拷贝写入为实验特性，可在设置中关闭
- XML 导出仍走文本路径（CDATA 转义需要）
- 当前只打包 `arm64-v8a`

### 升级说明

直接覆盖安装即可；设置、历史记录与自定义提示词都会保留。从 B1 升级后首次启动会看到 B2 公告，点「前往更新」可到 Releases 页。
