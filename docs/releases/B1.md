## Code PR B1

首个公开 beta，重点在**速度**和**界面**：扫描换成 C++、导出支持流式写入、UI 重做为 Material 3 Expressive。

### 新增

- **C++ 原生目录扫描**：JNI + NDK，一级子目录多线程遍历，文件大小由原生侧回传
- **流式导出**：边生成边写盘，`.part` 临时文件成功后原子改名，可在设置中开关
- **实验性零拷贝写入**：流式模式下直接写原始 UTF-8 字节，跳过解码/编码，可单独开关
- **有界并行读流水线**：关闭零拷贝时启用，窗口 6 文件 / 8MB
- **底部 Tab 导航**：`NavigationBar` + `SegmentedButton`，页面切换与列表入场动效
- **动态取色**：Android 12+ 跟随壁纸，低版本使用官方 baseline 色板
- **全英文 AI 提示词**：无 emoji，按 Godot 4.4 / 4.6 / 4.7 注入差异化规则

### 改进

- 生成文档标题、说明、目录树全部英文化，目录以 `dir/` 表示，不再使用 emoji
- 内置排除列表扩充：依赖目录、前端缓存、字体、音视频、3D、压缩包、二进制、Office、数据库等
- 历史记录改为后台加载，流式结果只保存预览，启动更顺
- 依赖升级：Compose BOM 2026.01.01、Material3 1.4.0、Kotlin 2.3.0
- 构建环境：JDK 21、compileSdk 37、Build Tools 37.0.0、NDK 30、CMake 4.1.2

### 修复

- 移除冗余的 `material` / `appcompat` 依赖与 `viewBinding`，减少资源合并开销
- 修复大项目下目录树构建 O(n²)、排序重复小写化、行数统计逐字符循环

### 性能

- 目录遍历：C++ 多线程
- 文件读取：并行流水线 + 64KB 缓冲
- 输出：流式写盘 / 零拷贝（实验）

### 构建信息

- JDK 21 / Gradle 9.0.0 / AGP 8.13.0
- compileSdk 37 / targetSdk 34 / minSdk 28
- NDK 30.0.15729638 / CMake 4.1.2

### 已知限制

- 零拷贝写入为实验特性，遇到异常可在设置中关闭
- XML 导出仍走文本路径（CDATA 转义需要）
- 当前只打包 `arm64-v8a`

### 升级说明

直接覆盖安装即可，历史记录与设置会保留。
